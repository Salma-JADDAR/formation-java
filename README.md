# Formation Java

## Présentation

Ce repository regroupe l'ensemble de mes travaux réalisés dans le cadre de ma **formation Java à YouCode**.

Il rassemble les différents **briefs, exercices pratiques et travaux réalisés** au cours de la formation, avec pour objectif de centraliser les productions et de suivre progressivement mon parcours d'apprentissage et de mise en pratique du langage **Java**.

## Objectif

Ce repository constitue un espace de travail et de suivi dédié à ma formation, permettant de conserver, organiser et faire évoluer les différents travaux réalisés tout au long du parcours.
